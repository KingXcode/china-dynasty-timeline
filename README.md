# 华夏脉络 · 中国历史朝代时间轴

在线访问：[华夏脉络](https://kingxcode.github.io/china-dynasty-timeline/)

一个无框架、无构建依赖的中国历史朝代与并行政权网页。使用纯 HTML、CSS、JavaScript 与 SVG，支持直接打开 `index.html` 或通过任意静态服务运行。

## 功能

- 全局主线与 13 个时代 / 区域入口。
- 102 条主要王朝、诸侯与区域政权记录，传统十六国、五代与十国逐项展开。
- 同一水平线对应同一年；并行政权使用独立轨道，时间尺度全局一致。
- 长时段折叠有明确的波纹带、起讫年及折叠长度；可切换严格等比例。
- 搜索全部资料、切换年代表、缩放时间轴、查看同期政权与来源。
- 史前文化和三皇五帝与有数值纪年的政权分开，不伪造精确传说年代。
- 手机专用紧凑图：全部分支适配一屏宽，名称独立排版；压缩无事件空段并明确说明非等比例，同年仍对齐。
- 响应式布局、键盘操作、减少动态偏好、移动端详情面板。
- 无第三方脚本、字体请求、分析跟踪、账户或后端。

## 使用

打开 `index.html` 即可。也可以：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 数据与年代说明

资料集中在 `data.js`，每条记录都有起讫年、分组、地域、纪年说明与参考来源。负数表示公元前，公元纪年没有零年。`core` 控制是否显示在总览，所有条目都可通过时代入口、全部记录或搜索访问。

这是扩展学习年表，不是全部地方势力和短期政权的穷尽名录。部分政权的创立、称帝、改国号、迁都、失去核心领土与残余政权终结不是同一时间，所以相关条目明确说明采用的口径。部分参考资料为学术或博物馆通用年表，部分为对应政权条目。现代记录不属于帝制朝代，按政权及政体延续说明。

图中的轨道位置不代表地理方位、疆域大小或正统地位；少量虚线是选取的承续关联，不是完整政治继承或征服关系图。时代视图会在所选时间边界裁切过长条带，但标签保留政权完整起讫年份。

`app.js` 中的折叠算法只折叠无已绘制起讫节点的长区间，所有轨道共用同一个映射。精确模式完全关闭折叠。SVG 条带本身从未因标签可读性而拉长，标签碰撞通过分配额外轨道解决。

## 检查

```sh
node --check app.js
node --check data.js
node tests/data.test.cjs
node tests/scroll.test.cjs
```

包含数据唯一性、年代、来源引用、传统十六国/五代/十国计数、关键重叠关系、公元无零年、手机宽度适配，以及 DOM 模拟下的刻度与滚动回归测试。

手机浏览器工具栏与键盘只改变可视高度时不会重建图表；实际宽度变化时先完整构造新图再一次替换，避免临时清空长页面导致滚动跳位。

## 发布

GitHub Pages 使用 `main` 分支根目录，`.nojekyll` 确保按静态文件发布。不需要 npm、Vue、打包工具或第三方 CDN。修改文件后提交到 `main` 即可更新。

## 目录

- `index.html`：页面结构与阅读说明。
- `style.css`：布局、响应式和视觉样式。
- `app.js`：交互与 SVG 时间轴。
- `data.js`：完整资料、年代注释与来源。
- `tests/data.test.cjs`：无需安装依赖的数据与刻度测试。

公开参考资料版权归各原作者所有。页面文字为摘要，不复制用户参考照片；未将参考照片上传到仓库。
